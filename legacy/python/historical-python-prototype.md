# Historical Python prototype (not deployed)

**Archived development version.** Start with the [current project README](../../README.md) for the playable browser game, setup and presentation link.

The first version of Museum Mystery was a small Streamlit app (`app.py`, `game.py`, `storage.py`) with pytest tests in `tests/`.
The game today runs entirely in `web/` and does not use any of this code.
It stays here so its history is kept. Run the old tests from this folder with `uv run pytest` (or `python3 -m pytest` if pytest is installed).
